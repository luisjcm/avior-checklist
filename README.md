# Avior Airlines · Check List Aeropuerto (PWA)

```bash
npm install
npm run dev        # http://localhost:5173 (accesible desde el móvil en la misma red)
npm run build      # genera /dist
npm run preview
```
Para instalar como PWA en el móvil se requiere HTTPS (p. ej. Netlify, Vercel, Cloudflare Pages).
Datos guardados en localStorage (clave `avior-checklist-v1`). Botón "Nuevo" reinicia el checklist.
